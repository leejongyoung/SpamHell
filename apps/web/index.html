같은 시드와 같은 글이면 npm, Python, CLI에서도 같은 결과가 나옵니다.

  1. 상황 고르기받은 문자를 붙여넣거나 상황을 직접 고릅니다.
  2. 굴리기마음에 들 때까지 다시 굴립니다. 직접 고쳐 써도 됩니다.
  3. 보내기위쪽 화살표를 누르면 문자 앱이 열립니다. 전송은 문자 앱에서 직접 누르세요.

입력한 번호와 문자는 이 기기 밖으로 나가지 않습니다. 휴대폰이 아니거나 문자 앱이 열리지 않으면 복사해서 붙여넣으세요.

05AI에 연결하기

MCP 서버(spamhell-mcp)를 연결하면 Claude 같은 AI 비서가 받은 문자를 읽고 알맞은 상황을 골라 답장을 만들어 줍니다. 네트워크나 파일 접근 없이 텍스트만 돌려줍니다.

  • spamhell_list_situations상황 목록과 예시 문자 보기
  • spamhell_reply상황에 맞는 답장을 스팸체로 생성
  • spamhell_transform글을 스팸체나 한국인체로 변환
  • spamhell_template풍자 템플릿 하나 가져오기
  • spamhell_list_templates템플릿 종류 보기

“이 문자에 맞는 답장을 스팸체로 만들어줘: 고객님 계좌가 정지될 예정입니다”

06지키는 원칙

  • 보내는 건 사람이

    문자 앱을 본문이 채워진 채로 열 뿐입니다. 자동 전송, 대량 생성, 일괄 처리는 만들지 않습니다.

  • 사칭하지 않기

    답장과 템플릿은 실제 기관이나 발신자를 사칭하지 않도록 씁니다. 풍자는 풍자로 남깁니다.

  • 내 기기 안에서

    변환과 상황 찾기는 브라우저 안에서 일어납니다. 입력한 글과 번호를 서버로 보내지 않습니다.
